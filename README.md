# 🧪 Urban Routes — QA Sprint 2

Projeto desenvolvido durante o **Bootcamp de Analista de QA da TripleTen**, com foco em **design de testes e análise de requisitos**.

Neste projeto, apliquei técnicas de QA para projetar cenários de teste, identificar classes de equivalência e valores-limite e desenvolver casos de teste para funcionalidades do Urban Routes.

## 🎯 Objetivo do projeto

Aplicar técnicas de design de testes para validar requisitos do sistema e criar uma cobertura de testes eficiente, considerando cenários positivos e negativos.

## 🔎 Atividades realizadas

- Análise de requisitos
- Design de testes
- Identificação de classes de equivalência
- Definição de valores-limite
- Criação de cenários positivos e negativos
- Elaboração de casos de teste
- Documentação dos resultados

## 🧠 Técnicas de design de testes

### Classes de equivalência

Utilização de classes de equivalência para dividir os dados de entrada em grupos com comportamentos semelhantes, reduzindo a quantidade de testes necessários sem comprometer a cobertura.

### Valores-limite

Aplicação da técnica de valores-limite para testar valores próximos aos limites permitidos pelos requisitos, incluindo valores válidos e inválidos.

## 📝 Funcionalidade analisada

Durante o projeto, foram analisados campos relacionados ao formulário **“Adicionar carteira de motorista”**, incluindo:

- Nome
- Sobrenome
- Data de nascimento

A partir dos requisitos desses campos, foram definidas classes de equivalência e valores-limite para elaboração dos testes.

## 📈 Aprendizados

Este projeto aprofundou minha experiência em planejamento e design de testes, permitindo transformar requisitos de software em cenários de teste estruturados.

Também desenvolvi a capacidade de selecionar dados de teste de forma estratégica utilizando classes de equivalência e valores-limite.
